# 评测答案格式

`scripts/benchmark.py` 用一份“标准答案”给待测版本打分。答案只存文本，不存视频；评测需要你自己的原素材和你认可的剪辑版本，仓库里只有 `example/answer.json` 这份假数据样例。

## 字段

| 字段 | 含义 |
|---|---|
| `name` / `source` / `note` | 名字、来自哪一版、你写的“这版好在哪”（给人看，不计分） |
| `tolerance` | 切点允许误差（秒），默认 0.5 |
| `media` | 素材清单：文件名＋时长，用来对上素材；**不写本机路径** |
| `steps` | 工序：源文件和时间段。`required: false` 表示加分项（如精剪才有的细节），不计入覆盖率 |
| `opening` | 允许的开头：只写 `file` 表示该素材任意段都可；写 `in`/`out` 表示首镜头至少一半要落在这段里 |
| `shot_count` / `duration` | 镜头数、成片秒数的允许范围（含封面占位） |

## 计分（满分 100）

- 工序覆盖 50：待测版本在同一源文件覆盖某工序时间段一半以上，算有这道工序
- 开头 15、切点 15（已覆盖工序中入出点都在误差内的比例）、镜头数 10、时长 10
- 硬性错误每条扣 25，并标“不合格”：同源选段重叠（“用途”含“回放”除外）、HDR 未转、出点超出素材时长、选片表目录没有通过的看图校验

分数只按时间段计算，不能证明“有效动作”写得对；看图能力仍以选片对照图为准。
